# Йога

Личное PWA для айфона: подбирает программу занятий по анкете, ведёт по занятию (фигурка позы,
таймер, голос), записывает тренировки и показывает прогресс. Все данные — только на телефоне
(IndexedDB); GitHub Pages раздаёт файлы приложения и обновления. Спека — [SPEC.md](SPEC.md).

## Установка на айфон

1. Открыть адрес приложения в Safari.
2. «Поделиться» → «На экран „Домой“».
3. Открыть с иконки — дальше работает и без интернета.

## Разработка

```bash
npm install
npm run dev        # http://127.0.0.1:8684, галерея фигурок: /tools/pose-gallery/
npm test           # библиотека поз, подбор программы, ход занятия, адаптация, статистика, бэкап
npm run build      # проверка типов + сборка в dist/
npm run preview    # собранная версия на 8685
```

`?speed=20` в адресе ускоряет время занятия — чтобы проверить его целиком за пару минут.

## Устройство

| Где | Что |
|---|---|
| `src/data/poses.ts` | 61 поза и 4 дыхательные практики: фигурка, шаги, подсказки, противопоказания, цели |
| `src/lib/figure.ts` | фигурка по углам суставов: решатель (в т.ч. «дотянуться до пола»), отрисовка |
| `src/lib/planner.ts` | подбор занятий и программы на 6 недель, короткие практики |
| `src/lib/session.ts` | ход занятия: подготовка/удержание, пауза, пропуск, +15 с, «полегче» |
| `src/lib/adapt.ts` | подстройка программы по оценкам и пропускам |
| `src/lib/stats.ts` | серии, минуты, освоение поз, самочувствие, тесты гибкости |
| `src/lib/voice.ts` | голос (синтез речи), сигналы, Wake Lock |
| `src/lib/backup.ts`, `src/lib/ics.ts` | бэкап JSON, события для Календаря |

## Инструменты

- `tools/pose-gallery/` — все фигурки на одном листе (красная рамка — опора висит над полом).
- `npx vite-node tools/fig-debug.ts <id>` — точки фигурки и зазоры опор.
- `npx vite-node tools/plan-debug.ts '<json анкеты>'` — распечатка занятия по минутам.
- `tools/art/` — иллюстрации поз через OpenRouter (модель google/gemini-3.1-flash-image, ≈$0,07 за картинку):
  `gen.ts [id…] [--note "…"] [--model …]` → art/raw, `build.ts` → public/poses + src/data/art.ts,
  `sheet.ts` — листы «схема ↔ картинка» для проверки глазами, `icon.ts && npm run icons` — иконка.
  Образец стиля — art/style.png, описания поз — tools/art/prompts.ts.
